# Visite 3D — appartement réel, Berlin (démonstration)

Visite libre, dans le navigateur, d'un **appartement réel situé à Berlin**, reconstruit en 3D (Gaussian Splatting) à partir
de ses photographies. Démonstration technique : **ce n'est pas un bien à vendre ni à louer**.

**Données** : jeu « Berlin » de *Zip-NeRF: Anti-Aliased Grid-Based Neural Radiance Fields* — J. T. Barron, B. Mildenhall,
D. Verbin, P. P. Srinivasan, P. Hedman (Google, ICCV 2023), https://smerf-3d.github.io/ — licence
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/). **Modifications** : reconstruction 3D, mise à l'échelle estimée,
plan schématique, vignettes réduites des photographies.

Visionneuse : three.js (MIT) et GaussianSplats3D 0.4.7 (MIT, copie modifiée : tri des splats plus fréquent).
